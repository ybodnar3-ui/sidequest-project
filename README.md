# SideQuest 🎲

Персональний «майстер гри життя». Щоранку — один персональний сайд-квест (5–15 хв),
адаптований під твоє місто, погоду й настрій. Виконав → відмітив → отримав нагороду →
стрік росте. Мінімум тиску, максимум «о, прикольно, я сьогодні зробив щось нове».

## Що це

- 🎯 **Один квест на день** (за замовчуванням) — ненапряжно, але різноманітно.
- 🌍 **Контекстна персоналізація** — AI враховує місто, погоду, настрій та історію.
- 🏆 **Гейміфікація** — XP, рівні, стріки + опційні модулі нагород (магазин, грошовий банк).
- 📱 **PWA** — ставиться на телефон, шле пуш-нагадування.

## Статус

🚧 У розробці. Фаза 1 — MVP під одного користувача.
